# Khanyisa's Artisan Bakery  Part 2 Submission

## Project Overview
This repository contains the enhanced frontend website for Khanyisa's Artisan Bakery, developed for Part 2 of the web development assessment. The project features external CSS styling, responsive layouts using media queries, and modern UI components.

## Features Implemented in Part 2
* **External Stylesheet (`style.css`):** Consolidated all styling into a master stylesheet linked across all HTML pages.
* **CSS Reset & Variables:** Implemented modern CSS variables for color schemes and a standard CSS reset for cross-browser consistency.
* **Layout Structures:** Utilized Flexbox and Grid for responsive header, navigation, and product presentation.
* **Responsive Design:** Added media queries to adjust breakpoints for mobile, tablet, and desktop screens.
* **Interactivity:** Added hover states, focus effects, and transitions for buttons and navigation links.
